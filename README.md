# 权衡 Scale · 基于 AHP 的多准则决策助手

> 把「我到底该选哪个」拆成层次、算成权重、检验是否自洽，再告诉你这个结论在什么条件下会被推翻。

**在线地址**：https://eoiec.github.io/scale/

**仓库地址**：https://github.com/eoiec/scale

> 零依赖单页应用，打开即用，无需登录、无需安装。断网也可离线运行（CSS/JS 全内联）。

## 为什么做这个

面对「考研还是就业」这类选择，人的直觉在两个地方会失效：

1. **装不下**。同时权衡五个维度，脑子会自动简化成「感觉哪个更好」，而这个感觉往往被最近一次情绪主导。
2. **会打架**。你觉得 A 比 B 重要、B 比 C 重要，转头又觉得 C 比 A 重要——这种自相矛盾自己很难发现。

AHP（Analytic Hierarchy Process，层次分析法）的价值就在这两点上：把前者拆成可计算的层次结构，把后者变成**可检验的数字**。

## 核心算法

### 一、构造判断矩阵

对同一层 n 个元素两两比较，用 1–9 标度记录相对重要程度，得到正互反矩阵 A
（a<sub>ij</sub> = 1/a<sub>ji</sub>，a<sub>ii</sub> = 1）。

| 标度 | 含义 |
|---|---|
| 1 | 两者同等重要 |
| 3 | 前者稍微重要 |
| 5 | 前者明显重要 |
| 7 | 前者强烈重要 |
| 9 | 前者极端重要 |
| 2, 4, 6, 8 | 相邻判断的中间值 |

### 二、求权重：几何平均法

```
wᵢ = ( ∏ⱼ aᵢⱼ )^(1/n)  /  Σₖ ( ∏ⱼ aₖⱼ )^(1/n)
```

它等价于**对数最小二乘**意义下的最优解，比算术平均更符合比较的乘性本质，也没有特征向量法在小矩阵上的迭代收敛问题。

### 三、一致性检验

判断完全自洽时应有 a<sub>ij</sub> · a<sub>jk</sub> = a<sub>ik</sub>，此时最大特征根 λmax = n。偏离越大，λmax 越大于 n：

```
CI = (λmax − n) / (n − 1)
CR = CI / RI
```

RI 为同阶随机矩阵的一致性指标均值（n = 3~9 取 0.58、0.90、1.12、1.24、1.32、1.41、1.45）。
**CR < 0.10 视为可接受。**

### 四、层次总排序

```
Wᵢ = Σₖ  wᶜₖ · wᵃ|ᵏᵢ
```

准则权重 × 各准则下方案权重，逐层加权汇总。

### 五、传递补全（本应用加的功能）

完整两两比较需要 n(n−1)/2 次判断，5 个准则就要 10 次，很容易填到一半就烦了。
本应用支持只填一部分，其余沿比较关系做**广度优先推导**：在对数尺度上按
`log aᵢⱼ = xᵢ − xⱼ` 传播，再吸附到最近的合法标度。

例：填入「性能:价格 = 5」「价格:便携 = 3」，自动推出「性能:便携 = 5×3 = 15 → 吸附到 9」。

### 六、敏感性分析（本应用加的功能）

一个静态排名说服力有限。更有意义的问题是：**我的结论在什么条件下会被推翻？**

把某个准则的权重从 0% 扫到 100%（其余按原比例缩放保持和为 1），记录首选方案改变的临界位置，即**翻盘点**。

- 全程不翻转 → 结论对该准则不敏感，可以放心采纳
- 翻盘点离当前值很近 → 这个准则就是决策的胜负手，值得再认真想一遍

## 功能

- **决策建模**：自定义方案与准则（各 2~9 个），支持多个决策并存、随时切换
- **两两比较**：1–9 标度可视化选择，进度条 + 配对一览 + 键盘左右键导航
- **传递补全**：填一部分即可推导剩余判断
- **权重结果**：方案总排序、准则权重、准则×方案热力表
- **敏感性分析**：拖动准则权重看实时排名变化，自动扫描翻盘点
- **矩阵与检验**：全部判断矩阵摊开看，λmax / CI / CR 三指标，标红不自洽的格子并列出建议复核的三元组
- **数据可携**：JSON 导出 / 导入，localStorage 持久化
- **响应式**：桌面侧边栏，≤760px 自动切底部导航栏

## 内置示例

「毕业去向怎么选」——5 准则 × 4 方案，共 40 组比较，全部通过一致性检验（最大 CR 0.0168）：

| 排名 | 方案 | 综合权重 |
|---|---|---|
| 1 | 考研 | 33.4% |
| 2 | 考公考编 | 24.9% |
| 3 | 出国留学 | 22.9% |
| 4 | 直接就业 | 18.8% |

准则权重：长期发展 41.7% > 个人兴趣 26.3% > 上岸难度 16.0% > 家庭期望 9.7% > 经济成本 6.2%。

翻盘点示例：当「长期发展」的权重降到 **19% 以下**时，首选方案会从考研变成出国留学。

## 已知边界

- AHP 假设准则相互独立，现实中准则常有重叠，会放大某些因素的权重
- 1–9 标度是离散的，细微偏好表达不出来
- 方案增删会改变判断矩阵，进而可能改变既有排序（秩反转），AHP 对此没有根本解法
- 输出是「在你说出的偏好下最自洽的答案」，不等于客观上最优
- 数据在浏览器本地，换设备或清缓存前请先导出 JSON
